# Session Titles

- Once the current task has a clear subject, name it once as `MMDD｜类型｜主题` using a supported title-management tool. Derive the date from the task's `createdAt` in `{{TITLE_TIMEZONE}}`, never from its last update or today's date.
- Choose one type: 功能、设计、修复、优化、发布、探索、文档、研究. Keep the topic short and specific, without repeating the project name or exposing private details.
- Rename only the current task's default/generated title when its origin is known; preserve manually chosen titles. If the metadata, title origin, subject, or supported tool is unavailable, leave the title unchanged and continue the task.
- Do not rename projects, change task contents, reorder, pin, archive, or edit internal state databases. Batch renaming and later retitling require a separate user request.
